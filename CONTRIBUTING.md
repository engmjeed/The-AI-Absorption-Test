# Contributing

Thanks for helping improve the AI Product Survival Test.

The framework is intentionally small. Contributions should make it clearer, more consistent, more testable, or more useful across different product categories.

## Good contributions

You can contribute by:

- Improving a scoring rubric or reducing ambiguity.
- Proposing a new test with a clear reason it is not already covered.
- Challenging an existing test or weight.
- Adding an illustrative example.
- Adding or improving a translation.
- Improving the JSON schema or structured-output format.
- Fixing unclear wording, inconsistencies, or calculation errors.

## Before adding a new test

Please ask:

1. Does this measure a genuinely different source of product durability?
2. Is it already captured by absorption resistance, AI tailwind, wrapper dependence, compounding assets, workflow depth, replication resistance, AI-expanded problems, or model independence?
3. Can the test be scored consistently from 0–4?

Avoid adding multiple questions that measure the same underlying risk in slightly different language.

## Adding an example

Examples should:

- Describe the product archetype clearly.
- State whether it is hypothetical/illustrative or based on documented public facts.
- Include all eight dimension scores and the weighted total.
- Explain what AI is likely to absorb.
- Explain what can remain defensible.
- End with one decisive question.

If you use a named real-world company, cite reliable public sources and avoid presenting interpretation as fact.

If you propose changing weights, explain which product archetypes become more accurately evaluated and why.

## Translations

Translations should preserve the meaning and scoring logic rather than translating terminology literally when that would make the text less natural.

Suggested naming:

`PROMPT_<LANG>.md` for full versions and `LITE_<LANG>.md` for Lite versions.

## Pull requests

Keep pull requests focused. Explain:

- What changed.
- Why it improves the framework.
- Whether it changes scoring or only wording/documentation.
